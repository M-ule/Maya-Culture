마야 문명 생산 계산기 시뮬레이터

입력 가능 (노란색)
자동 계산

1단계 · 기초 자원 생산 (옥 · 흑요석 · 깃털)

자원/건물레벨생산 방식건물 수운영 시간(h)현재 보유량잔여/부족판정소요 시간(h)예상 생산량예상 소비량

2단계 · 상품 생산 (마스크 · 달력돌 · 단검 · 머리장식)

상품/건물레벨생산 방식건물 수운영 시간(h)예상 생산량옥 사용량흑요석 사용량깃털 사용량
1. 불가사의와 보너스 적용 레벨을 입력하면 자원 생산 보너스가 자동 반영되고 추가 일꾼 수와 다음 증가 레벨이 표시됩니다.
2. 자원과 상품의 생산 시간, 건물 수, 현재 보유량 등을 입력하면 생산량·사용량·소비량과 판정 및 충분 시간을 계산합니다.
3. 최종 상품의 현재 보유량은 불가사의 계산기 탭에서 입력하세요.
4. 이전 레벨 건물 추가 시 소수점을 활용해보세요. Ex) 6레벨 자원, 생산건물에서 5레벨 건물 한 개 추가시 0.66, 4레벨 추가시 0.44 (정밀값은 아님)
5. 일괄 운영 시간을 기본으로 사용합니다. 운영 시간이 입력된 행은 해당 시간이 우선 적용됩니다.
6. 소요 시간(h)은 현재 운영 시간과 무관하게 현재 보유량을 포함해 판정이 처음 '잔여'가 되는 총 운영 시간입니다.
7. 기초 자원은 행복도 0% 기준값을 사용합니다. Ex) 행복도 50% 건물 1개라면 건물 수를 1.5로 환산해 입력하세요.
8. 상품은 행복도 100% 기준값을 사용합니다. 행복도가 다르면 직접 환산해야 합니다.
상품현재 보유량잔여/부족판정소요 시간(h)목표 구간 소비량상품 예상 생산량예상 보유량
1. 현재 레벨과 목표 레벨을 입력하면 해당 구간의 상품 소비량을 계산합니다.
2. 현재 보유량은 현재 가지고 있는 상품 수량을 직접 입력합니다.
3. 상품 예상 생산량과 상품별 소요 시간은 생산 계산기의 레벨·생산 방식·건물 수 설정을 기준으로 계산합니다.
4. 목표 레벨은 현재 레벨보다 낮게 설정할 수 없으며, 낮은 값을 입력하면 현재 레벨로 자동 보정됩니다.
