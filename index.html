상품 건물 상세 설정

건물 구성에 맞게 레벨, 건물 수, 행복도를 입력하세요. 행복도는 상품 생산량에만 반영되고, 옥·흑요석·깃털 사용량은 행복도와 관계없이 각 레벨의 건물 수를 기준으로 계산합니다. 상세 설정을 사용하면 기본 표의 레벨·건물 수·행복도는 상세 구성에 따라 자동 표시됩니다.
1. 불가사의와 보너스 적용 레벨을 입력하면 자원 생산 보너스가 자동 반영되고 추가 일꾼 수와 다음 증가 레벨이 표시됩니다.
2. 자원과 상품의 레벨, 생산 방식, 건물 수, 행복도(%), 운영 시간(h), 현재 보유량 등을 입력하면 각 항목을 자동으로 계산합니다.
3. 일괄 운영 시간을 기본으로 사용합니다. 운영 시간(h)이 입력된 행은 해당 시간이 우선 적용됩니다.
4. 자원의 소요 시간(h)은 현재 보유량을 포함하여 잔여/부족이 처음 ‘잔여’가 되기까지 필요한 운영 시간입니다.

1. 1단계: 현재 레벨과 목표 레벨을 기준으로 필요한 상품량과 목표 달성 여부를 계산합니다. 소요 시간(h)은 현재 보유량을 포함하여 부족한 상품이 처음 ‘잔여’가 되기까지 필요한 운영 시간입니다.
2. 2단계: 수면까지 남은 시간(h) 동안의 자원 생산, 상품 생산에 사용되는 자원, 자원의 현재 보유량을 함께 반영하여 수면 중 필요한 자원을 확보하기 위한 생산력을 계산합니다. 수면 요구량은 각 상품 건물의 현재 레벨에서 이용 가능한 가장 긴 생산 방식 × 3회를 기준으로 합니다.
3. 3단계: 현재 생산력과 목표 레벨 달성에 필요한 생산력을 비교하여 생산력 차이를 계산합니다.
※ 생산력은 행복도 100%의 Lv6 건물 1개를 100으로 둔 지수입니다. 현재 생산력은 현재 설정된 건물 구성의 생산 능력을 나타내며, 필요 생산력은 각 단계에서 현재 보유량을 고려해 목표를 충족하는 데 필요한 생산 능력을 환산한 값입니다.
